# 2019 ~ 2020 Toy Projects (총 4개)

## 4차 프로젝트 – GE Project
**기간**: 2019.01.17 ~ 2020.03.30  
**인원**: 6명  

### 개요
중소기업을 위한 **그룹웨어 시스템 개발**

### 담당 업무
- File Upload 방식의 전자결재 시스템 개발 (총 17 JSP 파일)
- DB 설계 및 파일럿 테스트
- 양식 다운로드 게시판 개발
- CSS 작업 및 통합 작업

### 개발 환경 & 도구
- **OS**: Windows  
- **Front-End**: HTML 4.01 / HTML5, CSS3, JavaScript, ECMAScript 3, Ajax, jQuery 1.11, JSON, XML  
- **Back-End**: JDK 1.7.0, Apache Tomcat 8.0, Spring Framework 3.2, Oracle 11g, MyBatis 3.2, MyBatis-Spring 1.2, Amazon RDS  
- **Open API & Library**: Ojdbc6, Fullcalendar 2.9.1, datetime-picker, log4j 1.2, smart_editor2, cos.jar, json_simple 1.1  
- **Tool**: Eclipse Luna, Erwin, Oracle SQL Developer 18.1, Chrome 80, IE 11, Google Office, Kakao Oven

## 3차 프로젝트 – MODEL2 + MVC (Spring)
**기간**: 2019.01.16 ~ 2020.01.31  
**인원**: 1명  

### 개요
MODEL2 + MVC 패턴 기반의 **Spring 게시판 및 회원가입 페이지** 구현

### 주요 기능
- 게시판: JSTL 적용
- 회원가입: EL 적용
- Ajax 기반 ID 중복 체크
- jQuery Password Validation
- cos.jar 파일 업로드
- Daum 주소 API를 이용한 회원가입
- 네이버 SmartEditor2 API로 글 작성

### 개발 환경 & 도구
- **OS**: Windows  
- **Server/Back-End**: JDK 1.8, Apache Tomcat 8.0, Spring Framework 3.2.4, MyBatis 3.2.4, MyBatis-Spring 1.2.2, Oracle 11g, JDBC Thin Driver(ojdbc6.jar)  
- **Front-End**: HTML4, JavaScript, AJAX, jQuery  
- **API**: Daum Kakao MAP API, Naver SmartEditor2 API  
- **Tool**: Eclipse Luna, Oracle SQL Developer  
- **Encoding**: EUC-KR
